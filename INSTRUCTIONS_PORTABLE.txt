    LBC AUTOMATION - GUIDE D'UTILISATION
═══════════════════════════════════════════════════════════

Bienvenue ! Cette application vous permet de centraliser vos
emails Leboncoin depuis plusieurs comptes Gmail.

───────────────────────────────────────────────────────────
📋 CONTENU DU DOSSIER
───────────────────────────────────────────────────────────

✓ LBC-Automation.bat          → Fichier principal pour lancer
✓ install-chrome.bat          → Script pour installer Chrome (si erreur)
✓ install-chrome.ps1          → Script PowerShell (alternative)
✓ node-portable/               → Node.js embarque (ne pas toucher)
✓ app/                         → Code de l'application (ne pas toucher)
✓ INSTRUCTIONS_PORTABLE.txt    → Ce fichier

───────────────────────────────────────────────────────────
🚀 COMMENT LANCER L'APPLICATION ?
───────────────────────────────────────────────────────────

1. Double-cliquez sur "LBC-Automation.bat"

2. Une fenetre noire (console) s'ouvre
   → C'est normal, ne la fermez pas !

3. Apres quelques secondes, votre navigateur s'ouvre
   automatiquement sur http://localhost:3001

4. Utilisez l'application normalement :
   - Cliquez sur "Rafraichir les emails"
   - Utilisez les filtres par categorie ou par compte
   - Cliquez sur un email pour ouvrir Leboncoin

───────────────────────────────────────────────────────────
🛑 COMMENT ARRETER L'APPLICATION ?
───────────────────────────────────────────────────────────

METHODE 1 (Recommandee) :
→ Fermez la fenetre noire (console)
→ L'application s'arrete immediatement

METHODE 2 :
→ Dans la fenetre noire, appuyez sur Ctrl+C
→ Confirmez avec "O" (Oui)

───────────────────────────────────────────────────────────
🆘 DEPANNAGE
───────────────────────────────────────────────────────────

PROBLEME 1 : Rien ne se passe quand je double-clique
------------------------------------------
Solution :
→ Clic droit sur LBC-Automation.bat
→ "Executer en tant qu'administrateur"

PROBLEME 2 : Erreur "Node.js portable non trouve"
------------------------------------------
Solution :
→ Le dossier "node-portable" est manquant
→ Verifiez que vous avez bien decompresse TOUT le .zip
→ Retelecharger le package complet si necessaire

PROBLEME 3 : Le navigateur ne s'ouvre pas
------------------------------------------
Solution :
→ Ouvrez manuellement votre navigateur
→ Allez sur : http://localhost:3001

PROBLEME 4 : "Port 3001 deja utilise"
------------------------------------------
Solution :
→ Une autre instance est deja lancee
→ Fermez toutes les fenetres LBC Automation
→ Attendez 10 secondes et relancez

PROBLEME 5 : Aucun email ne s'affiche
------------------------------------------
Cause : Probleme avec le Google Sheet ou identifiants
Solution :
→ Verifiez votre connexion internet
→ Verifiez que le Google Sheet "LBC-Automation" est accessible
→ Verifiez les identifiants dans le Sheet

PROBLEME 6 : Erreur "Could not find Chrome"
------------------------------------------
Cause : Chrome n'est pas installe pour Puppeteer
Solution :
→ Double-cliquez sur "install-chrome.bat"
→ Attendez la fin de l'installation (peut prendre 5-10 minutes)
→ Relancez LBC-Automation.bat

OU ALTERNATIVE :
→ Installez Google Chrome manuellement depuis :
  https://www.google.com/chrome/
→ L'application utilisera Chrome systeme automatiquement

NOTE : Si vous avez une erreur avec install-chrome.ps1 (script non signe),
       utilisez install-chrome.bat a la place (double-clic simple).
